# Euler’s Method – Jupyter Notebook

This repository contains a Jupyter Notebook implementation of **Euler’s Method**, a numerical technique for approximating solutions to ordinary differential equations (ODEs). It is based on exercises from the *Introduction to Dynamical Systems and Chaos* course on [Complexity Explorer](https://www.complexityexplorer.org).

## Overview
Euler’s Method uses discrete time steps to approximate the trajectory of dynamical systems. It is a simple yet powerful tool for exploring systems where analytical solutions are difficult to obtain.

## Contents
- `Newtons_Law_Of_Cooling.ipynb` – interactive notebook with step-by-step implementation  
- Worked examples (Newtons Law of Cooling)  
- Visualizations comparing numerical and analytical solutions  

## Requirements
- Python 3.x  
- Jupyter Lab / Notebook  
- NumPy  
- Matplotlib  

Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage
Launch Jupyter Lab and open the notebook:
```bash
jupyter lab Newtons_Law_Of_Cooling.ipynb
```

Run the cells interactively to explore Euler’s Method and visualize results.
